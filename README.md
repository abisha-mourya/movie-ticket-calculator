# movie-ticket-calculator
Beginner Python movie ticket calculator completed as part of the freeCodeCamp Python certification course.
# Description

A movie ticket calculator that determines ticket eligibility and calculates the final ticket price based on age, seat type, membership, weekend status, and show time.

# Concepts Used

- Variables
- Boolean values
- `if`, `elif`, and `else`
- Logical operators (`and`, `or`)
- Nested conditions
- Arithmetic operations

# Features

- Checks ticket eligibility
- Applies membership discounts
- Calculates additional charges
- Calculates service charges based on seat type
- Determines the final ticket price
